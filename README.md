# 藏经阁的最后一页

> 全宗门每天练的入门功法，是我父亲。

**题材**：仙侠 · 解谜　**作者**：灯下人　**30 章 · 92,138 字**

青云宗三百年，功法不绝。弟子练的每一本秘籍，都是从后山墨池里抄出来的。抄一本书要一份原稿，原稿是人。每过几十年，宗门往后山送一个人，那个人被写成一本书，从此世上再没有他。

沈砚是藏经阁的扫地杂役。某个雨夜，他翻到了《引气篇》的最后一页——六行血字，六种笔迹，六个日期。最后一行是他父亲的字。

第七行空着。
